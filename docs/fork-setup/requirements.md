# 要件：フォークのセットアップ

- 人がやるのは、Cloudflare の API トークンの作成と、外部の画面にしか無い作業（Discord の Bot、Zero Trust の組織の最初の作成、ドメインの選択、許可するメールアドレスを伝えること）だけにする。ほかは Claude Code がスクリプトと `gh` で進められる。
- スクリプトは手元の PC で動かす。CI からは使わない。
- シークレットの値（トークン・メールアドレス・アカウントID）は画面に出さず、子プロセスには stdin で渡す。子プロセスはシェルを通さず、引数の配列で起動する。エラー出力を見せるときも値を伏せる。
- `--dry-run` は Cloudflare を読むだけで、何も作らず、何も入れない。
- 既存の Access アプリは書き換えない。足りない設定は警告して、ダッシュボードで直してもらう。同じホスト名のアプリが複数あるときは止まる。
- Access アプリを作るときは、メールアドレス1件だけを Allow し、Managed OAuth と DCR をオンにし、redirect URI を claude.ai と claude.com のコールバックに限る。
- 何度実行しても同じ結果になる（値の上書きだけ）。
- 本物のホスト名・AUD・アカウントID・サーバーID・メールアドレス・トークンをリポジトリに書かない。
